Add the Homograph Guard extension to your browser

The app is installed and the browser helper is registered. Browsers only let you add an extension that is not from their store yourself - it takes a minute and is done once.

Folder to select

extension

Copied. Paste it into the folder picker's address bar.

Microsoft Edge

  1. Type edge://extensions in the address bar and press Enter.
  2. Turn on Developer mode (left side, or bottom left).
  3. Click Load unpacked and select the folder above.
  4. Click the puzzle icon in the toolbar and pin Homograph Guard.

Google Chrome and Brave

  1. Type chrome://extensions (Brave: brave://extensions) in the address bar.
  2. Turn on Developer mode (top right).
  3. Click Load unpacked and select the folder above.
  4. Pin Homograph Guard from the puzzle icon.

Firefox

Firefox only keeps extensions that Mozilla has signed. Until a signed copy is published, you can try it for the current session:

  1. Type about:debugging#/runtime/this-firefox in the address bar.
  2. Click Load Temporary Add-on and choose manifest.json in the folder above.

To keep it permanently, sign it for free on addons.mozilla.org as a self-distributed add-on (see the project's README).

Check that it works

Open the extension's popup: it shows an on/off switch. Under Lists and privacy settings it should say Connected to the Homograph Guard app on this device.
